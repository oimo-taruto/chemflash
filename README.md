# ⚗️ ChemFlash — 高校化学（阪大薬学レベル）暗記事項チェック

フラッシュカード形式で無機化学の暗記事項を確認するWebアプリ。
ログイン不要・「同期ID」でクラウド保存／他端末から復元できます。

**公開URL: https://oimo-taruto.github.io/chemflash/**（GitHub Pages。`main` に push すると約1分で自動更新）

## 起動方法

ビルド不要の静的サイトです。どちらでも動きます。

- **そのまま開く**: `index.html` をダブルクリック（データはブラウザに保存されます）
- **ローカルサーバで開く**（推奨）: `powershell -ExecutionPolicy Bypass -File serve.ps1` → http://localhost:4173/

ファイル一式をどこに移動してもそのまま動きます。Netlify / GitHub Pages 等に置けばスマホからも使えます。

## 画面構成

| ページ | 内容 |
|---|---|
| `index.html` | アプリ本体（演習 / 復習 / 書庫 / 分析 / 保存 / 同期） |
| `admin.html` | 問題管理（CSVインポート・1問追加・編集・削除・エクスポート）。先生用。アプリからのリンクは無いのでURL直打ちで開く |

## 公式問題の配り方（先生向け）

問題データはアプリ本体（`js/store.js` の `SEED`）に焼き込まれており、**push すると次回アクセス時に全生徒の端末へ自動反映**されます（追加・修正・削除すべて。生徒の進捗・メモ・⭐・自作問題はそのまま残ります）。

手順: `admin.html` で問題を編集 →「⬇ エクスポート」でCSVを書き出す → Claude Code に「問題変えたよ」と渡す → SEED に反映して push。
CSVテキストを直接渡してもOK。

- 答えだけの修正は生徒の進捗を引き継ぎます（問題文を変えるとその問題の進捗はリセット）
- 生徒が端末側で公式問題を編集・削除していた場合はそちらが優先されます（自動で上書きしません）

## 機能

- **演習モード**: スタート画面で「出題数（10/20/30/全部/15分）・並び（ミックス＝インターリーブ／集中＝単元ごと）・範囲（全範囲/単元/分野/キーワード/難易度）・対象（未着手優先/全部/苦手だけ）」を選んで開始。途中で「ストップ」でき、結果サマリが出ます。各問は **3段階（🙅わからない／🤔あいまい／🙆完璧）** で自己評価。
  - **未習スキップ**: まだ授業で習っていない問題は「⤳ まだ習ってない」で出題・統計から除外できます（書庫でいつでも解除可）。
- **復習モード**（2本立て）:
  - 🔁 **間違い復習**: 「完璧」以外（わからない・あいまい）を今すぐ反復。完璧にすると外れる。
  - 📅 **今日の復習**: 忘却曲線（Leitner式）にそって「そろそろ忘れる頃」の問題が自動で出題。完璧で `1週間 → 1ヶ月` と間隔が伸び、2回こなすと🎓定着して外れる。間違えると最短に戻る。段階アップは1日1回まで。
- **📖 書庫**: 採点なしの閲覧モード。問題文・答え・キーワードで検索、分野/タイプ/難易度/状態で絞り込み。各問にステータス色バッジ（未着手/わからない/あいまい/完璧/🎓定着/未習）。テスト前の総ざらいに。
- **タグ活用**: タグをタップで書庫を絞り込み／答え合わせ後に「🔗 関連問題」リンク／分析で「キーワード別の弱点」を表示。
- **📊 分析（ヒートマップ）**: 一番上に「いま優先したい分野（弱点トップ3）」と 🎓定着・今日の復習・カバー率。単元タイルを理解度で色分け（赤=弱い）→タップで分野へドリルダウン。各指標は3色積み上げバー（完璧/あいまい/わからない）で表示。
  - 初回正答率 = 初回が「完璧」だった割合（あいまい・わからないは不正解扱い）
  - 理解度 = 解いた問題のうち最新が「完璧」の割合
  - カバー率 = （未習を除く）全問題のうち1回でも解いた割合
  - ※ 未習にした問題は分母から除外されます。
- **ひとことメモ**: 問題ごとにコメントを保存
- **⭐保存**: 大事な問題をストックして「保存」タブで見返せる
- **✏️ 自作問題**: 保存タブで生徒が自分の問題を作れる（テストで落とした知識の問題化に）。演習・復習（忘却曲線）にも普通に混ざり、分析では「自作問題」として独立集計。自分の端末（＋同期ID）だけのもので、他の生徒には配られない
- **同期**: 同期IDでクラウド保存・復元（下記）＋ JSONファイルでのバックアップ／復元
- **PWA**: 公開ドメインに置くとオフライン動作・ホーム画面への追加が可能（電車学習向け）。

> 忘却曲線・3段階評価まわりの設計意図は [DESIGN.md](DESIGN.md) を参照。

## CSVフォーマット

ヘッダー行はあってもなくてもOK（`sub-unit` 表記も可）。tags はスペース区切り（カンマ不可）。

```csv
question,answer,unit,sub_unit,question_type,tags,difficulty
"オストワルト法の第1段階で用いる触媒は？","白金 Pt（網状）",無機化学,窒素とその化合物,丸暗記,硝酸 オストワルト法 触媒,1
"黄リンを水中に保存する理由は？","空気中で自然発火するため。",無機化学,リンとその化合物,理由型,リン 保存 自然発火,2
```

- `question_type`: 「丸暗記」または「理由型」
- `difficulty`: 1〜3
- 同じ問題文は重複として自動スキップ（管理画面のチェックで上書きも可）
- 問題文を編集しても学習記録（進捗・メモ・⭐）は引き継がれます

## クラウド同期のセットアップ（1回だけ・無料・約5分）

無料で無登録のJSON保管サービスは現在ほぼ全滅しているため（jsonblob はCORS廃止、kvdb はメール認証必須 等）、
同期先には **自分専用の Firebase Realtime Database** を使います。設定は管理者が1回だけ。生徒側はログイン不要で、同期IDの入力だけです。

1. https://console.firebase.google.com にGoogleアカウントでログイン
2. 「プロジェクトを追加」→ 名前は何でもOK（Analyticsは無効でOK）
3. 「構築」→「Realtime Database」→「データベースを作成」（テストモードで開始）
4. 「ルール」タブを以下にして公開:
   ```json
   { "rules": { "chemflash": { ".read": true, ".write": true } } }
   ```
5. 「データ」タブ上部のURL（`https://xxxx-default-rtdb.....firebasedatabase.app`）をコピー
6. `js/sync-config.js` の `window.CHEMFLASH_SYNC_URL = ''` に貼り付ける
   （またはアプリの「同期」タブから各端末で設定してもOK）

設定後は「同期」タブ →「新しい同期IDを発行」→ 別端末でそのIDを入力して復元、という流れです。
同期ID設定中はデータ変更の数秒後に自動でクラウド保存されます。

> 同期サーバ未設定でも「ファイルでバックアップ／復元」で端末間の引っ越しができます。

## PWA（オフライン・ホーム追加）

`manifest.json` と `sw.js` を同梱しています。**公開ドメイン（https）に置いたときだけ** Service Worker が有効になり、オフライン動作・ホーム画面への追加ができます。`localhost` では開発中のキャッシュ混乱を避けるため自動で無効化されます（[app.js](js/app.js) のPWA登録部）。Service Worker は **ネットワーク優先**（オンライン時は常に最新、オフライン時のみキャッシュ）なので、問題やコードを更新しても古い内容が残りません。

## データの保存場所

すべてブラウザの `localStorage`（キー: `chemflash_data_v1`）。
ブラウザのデータ消去で消えるため、定期的にバックアップ書き出しか同期推奨。
（旧バージョンの2段階データは起動時に自動で3段階＋忘却曲線形式へ移行されます）
